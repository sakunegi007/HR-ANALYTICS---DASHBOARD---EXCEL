# HR Analytics Performance Dashboard 📊

## 📌 Project Overview
This project is an HR Analytics Performance Dashboard created using Microsoft Excel.

The main objective is to analyze employee data and visualize important HR metrics through interactive charts and KPIs.

This is a beginner-level Data Analytics practice project designed to improve Excel, data analysis, and visualization skills.

## 🎯 Project Objectives
- Analyze total employee count.
- Compare active and inactive employees.
- Analyze average employee salary.
- Understand department-wise employee distribution.
- Analyze gender-wise and city-wise employee data.
- Evaluate employee performance ratings.
- Compare training hours with projects completed.
